# 松赞用户关系助手 Demo

Songtsam CRM Copilot 是一个移动端 H5 Demo，用于演示销售通过自然语言完成客户维护、提醒处理、客户分析、产品咨询和报价辅助。

## 技术栈

- React
- TypeScript
- Vite
- Tailwind CSS

## 本地启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`，可部署到 Vercel、Netlify 或任意静态网站托管服务。

## Demo 说明

- 全部数据为 Mock 数据
- 不依赖真实 AI API
- 不依赖真实 CRM / 企业微信接口
- 已预留后续接口接入位置
